Interface Application Web (Aperçu)

L'utilisateur explore le contenu complet de l'application directement dans le navigateur avant toute installation.

1. Consultation immédiate

L'application est pleinement fonctionnelle dès la première visite sur le navigateur web.

2. Mode Hors-Ligne

Toutes les ressources visitées sont mises en cache par le Service Worker pour une utilisation sans réseau.

3. Installation sur Demande

Le bouton d'installation s'affiche dans l'en-tête lorsque le navigateur confirme la compatibilité PWA.
